# SALKN

Лендинг кондиционеров и установки в Казани: **https://salkn.ru/**. Опубликован 16.09.2026 на REG.RU. Дополнительный домен salkn.online перенаправляет на основной.

Пять блоков, SVG-анимация воздуха, выбор бренда и реальные фотографии монтажа. Форма сохраняет заявки в MySQL, затем отправляет полную копию двум согласованным получателям Telegram. При сбое доставка повторяется заданием cron.

## Структура и запуск

- `dist/` — публичные HTML/CSS/JS, изображения и точки входа PHP API. Сборка не требуется.
- `server/` — закрытый PHP-обработчик, миграции и очередь. На хостинге размещены вне публичной папки.
- `scripts/` — локальные инструменты предпросмотра, публикации и проверки.
- `.env.local` — доступы, исключены из Git. Образец — `.env.example`.
- `.local/` — временные архивы и служебные секреты, исключены из Git.

Требуется Node.js, npm-зависимостей нет. `npm run dev` запускает предпросмотр на http://127.0.0.1:3000. Он не исполняет PHP и не отправляет заявки; рабочая форма — на salkn.ru.

`npm run check` проверяет JavaScript. `npm run verify:live` проверяет HTTPS, адреса, метаданные, закрытые пути и отказ для некорректных запросов. `node scripts/verify-live.mjs --submit-test` дополнительно создаёт одну настоящую тестовую заявку и отправляет обоим получателям; запускать только при необходимости.

`npm run hosting:status` показывает количество заявок, доставок, очередь и время запуска фонового задания без персональных данных.
