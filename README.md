# SALKN

Локальный лендинг кондиционеров и установки в Казани. Пять блоков, SVG-заставка, анимация воздуха, выбор бренда, галерея четырёх работ и форма предварительной проверки. Отдельные страницы политики и согласия содержат предоставленные владельцем реквизиты.

## Предпросмотр

Требуется Node.js. `npm run dev` открывает сервер на http://127.0.0.1:3000. Внешних зависимостей нет. `npm run check` проверяет синтаксис JavaScript.

Готовые статические файлы и исходники находятся в `dist/`; сборка не требуется. `scripts/serve.mjs` — только локальный сервер предпросмотра, не сервер приёма заявок. Не использовать его как готовый production backend.

## Следующий этап

Форма проверяет телефон, согласие и выбранный бренд. **Не отправляет, не записывает данные и не имитирует принятую заявку.** Telegram и база данных ещё не подключены. Владелец выбрал доставку полных заявок в Telegram; подготовка описана в `docs/reg-ru-deployment.md`. Никаких токенов и секретов в клиентском коде нет.

Перед публикацией пройти `docs/launch-checklist.md`, утвердить продавца и оператора, цены и документы, подключить сервер в РФ. Основной домен — `salkn.ru`, дополнительный — `salkn.online` с планируемым перенаправлением. Canonical и sitemap подготовлены; `dist/robots.txt` и meta robots закрывают предпросмотр от индексации до публикации.

Исследование предложений — `docs/competitor-notes.md`. Проверенные источники изображений и характеристик — `docs/product-sources.md`. Иллюстрация кондиционера в главном экране — условная брендовая SVG, не конкретная товарная модель. Оригинальные пользовательские материалы сохранены в корне.
